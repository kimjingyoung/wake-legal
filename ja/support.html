アラームが鳴りません

  1. 設定 → ラボ → テストアラームをタップして、お使いのスマホで鳴るかどうかをまず確認してください。
  2. iPhone：アラームと通知の権限、およびAppのバックグラウンド更新がオンになっていないと、「今すぐ」の起こしを受け取れません。iOS 26未満ではサイレントを突破できず、通知としてのみ届きます。
  3. Android：通知の権限、他のアプリの上に重ねて表示、バッテリー最適化の対象外を許可してください。アプリの設定画面に、オフになっている項目が表示されます。
  4. iPhoneをMacと連携して使っている場合（iPhoneミラーリング、MacでのiPhone通知の表示）、通知がMacに送られ、スマホの鳴動が遅れることがあります。就寝前にはMacを閉じるか、連携をオフにしてください。
  5. iPhoneのアラーム音量は、設定 → サウンドと触覚 → 着信音と通知音の音量に従います。0の場合はバイブレーションのみです。
  6. アプリを強制終了すると、iPhoneではアラームの代わりに通常の通知として届きます。アプリはそのままにしておいてください。
  7. 友だちがあなたを起こせない場合は、友だちが起こしてもOKと許可時間帯を確認してください。

Wakeは補助のアラームです。逃せない予定には、標準のアラームも併せてご利用ください。

友だちを招待するには

グループ画面の右上にある人のアイコン → 数字8桁のコードを伝えるか、共有をタップしてください。コードは24時間使用できます。

望まない相手に何度も起こされます

グループで、その相手のカードにある「⋯」→ ブロックまたは通報するをタップしてください。鳴動中のアラーム画面の下にある通報するからも行えます。ブロックするとお互いに起こせなくなり、通報したことは相手に通知されません。通報は24時間以内に確認します。禁止される内容と対応の基準は運営ポリシーに記載しています。

私の録音や動画が著作権を侵害していると考える権利者の方は、著作権侵害の通報手続に従ってお知らせください。

Wake+ サブスクリプションの解約・返金・復元

  • 解約：iPhoneは設定 → 自分の名前 → サブスクリプション → Wake+、AndroidはGoogle Playアプリ → プロフィール → お支払いと定期購入 → 定期購入 → Wake+から解約します。更新の24時間前までに解約すれば、翌月から請求されず、すでにお支払い済みの期間は最後までご利用いただけます。Wakeのアカウントを削除しても、サブスクリプションは自動的には解約されません。
  • 返金：決済はストアが処理するため、ストアに申請してください。Appleはreportaproblem.apple.com、Google Playは注文履歴から申請します（購入後48時間以内であれば、Google Playに直接申請できます）。難しい場合は、お問い合わせからご連絡ください。7日以内の契約申込みの撤回など、法令で定められた権利は、利用規約第5条の2に定めています。
  • 復元：スマホを替えた場合やアプリを再インストールした場合は、同じWakeアカウントでログインしてください。サブスクリプションはスマホではなくアカウントに紐づいているので、そのままご利用いただけます。Wake+の案内画面にある購入を復元もご利用いただけます。

個人情報の開示・訂正・削除の請求

名前・色・設定は、アプリの設定でそのまま確認・変更でき、削除は下記のアカウント・データの削除から行います。アプリからはできない開示や処理停止の請求は、お問い合わせまたはwake.official.kr@gmail.comへお送りください。10日以内にご返信します。詳しくはプライバシーポリシーの5をご覧ください。

アカウント・データの削除

アプリから直接削除する（最も早い方法）

Apple・Googleで連携したアカウント：アプリの設定 → アカウント管理 → 退会するをタップして確認すると、ただちにすべてのグループから抜け、設定した・受け取った予約アラームが取り消され、プッシュトークンが削除され、すべての端末でログアウトされます。その時点からだれもあなたを起こせません。アカウント・履歴・設定・Wake+の利用権は30日間保管され、その間に同じApple・Googleアカウントでログインし直すとアカウントが復元されます（まだ残っているグループと、メンバーがそのまま残っている起こしの許可も戻ります）。30日が経過すると、サーバーがアカウントとデータを削除し、その際に先にApple側の連携も解除します（解除に失敗しても削除は進みます）。自分しかいなかったグループも30日間は残し、アカウントとともに削除します。

連携していない（匿名の）アカウント：設定 → データを削除して退会をタップすると、アカウントと履歴がただちに削除されます。再度ログインできないため猶予期間はなく、元に戻すこともできません。

すでにアプリを削除した場合、または使えない場合

wake.official.kr@gmail.comへ「アカウント削除の請求」と書いてお送りください。アプリで使っていた名前（プロフィール名）と、参加していたグループ名をご記入いただければ結構です。匿名アカウントのため、本人確認として最後に利用した時期などをお尋ねすることがあります。AppleまたはGoogleで連携したアカウントの場合は、連携に使ったメールアドレスが手がかりになります。確認でき次第、ただちに削除してお知らせします（10日以内）。連携済みのアカウントであれば、アプリを再インストールして同じアカウントでログインし、上記の方法でご自身で削除することもできます。

すぐに削除されるものと残るもの

以下は、アカウントが実際に削除された時点から数えます。連携したアカウントは退会から30日後、匿名アカウントは削除した時点です。

  • すぐに削除：アカウント（名前・色）・設定・自分のアラーム・グループへの参加・起こしの履歴・端末情報（プッシュトークン）・端末のタイムゾーン・利用権・クーポン使用履歴、Apple連携の更新用トークン。
  • アカウントと切り離して5年間保管：Wake+の決済記録（ストアの取引識別子・商品・利用期間）。電子商取引法（전자상거래법）に基づく保管であり、5年後に削除します。
  • 録音・写真：アカウントを削除すると、2日以内にサーバーから削除されます（ライブラリに保存した録音を含みます）。処理中の通報に関わるものは、処理が終わるまで残ります。
  • 無料特典の利用記録：アカウントとの紐づけはただちに切り、同じスマホで無料特典を再度受けられないよう、使用した日から1年間保管した後に削除します。
  • 通報の記録：処理完了後1年間保管した後に削除します（処理前の場合は処理されるまで）。アカウントとの紐づけだけが切れ、通報の内容は残ります。
  • お問い合わせ：受付後1年間保管した後に削除します（アカウントとの紐づけは切れます）。
  • エラー診断の記録：発生した日から30日後に削除します。アカウントを削除しても、その間は残ることがあります。
  • 接続IPなどのログ：ホスティング事業者のログ保管ポリシーに従って残ることがあります。

詳しい保有期間はプライバシーポリシーの2をご覧ください。

サブスクリプションは別途解約が必要です

Wake+のサブスクリプションは、アカウントを削除しても自動的には解約されません。お支払いをした場所のサブスクリプション設定からご自身で解約してください。iPhoneはApp Store、AndroidはGoogle Playです。アカウントを削除する前に解約することをお勧めします。
